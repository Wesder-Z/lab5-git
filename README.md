**Борисов Анатолий Олегович, группа 221141, вариант 5, лабораторная № 5**

Дисциплина: «Методы и технологии программирования».

## Цель работы

Создать графическое приложение на Python с использованием Tkinter, освоить
виджеты, вкладки, меню, обработчики событий и работу с несколькими окнами.

## Задания варианта

| Сложность | № | Задание | Реализация |
|---|---:|---|---|
| Средняя | 5 | Программа со вкладками (`Notebook`) | Главное окно содержит три рабочие вкладки |
| Средняя | 7 | Окно с меню (`File -> Exit`) | Команда `Exit` закрывает главное и дочерние окна |
| Средняя | 1 | Окно с кнопкой «Привет» | Кнопка меняет текст приветствия на первой вкладке |
| Повышенная | 6 | Конвертер валют | Ввод суммы, выбор валют, проверка данных и вывод результата |
| Повышенная | 8 | Программа с несколькими окнами | Отдельное интерактивное окно со сведениями об авторе |

## Структура проекта

- `main.py` запускает приложение;
- `gui.py` содержит главное окно, вкладки и дополнительное окно;
- `currency.py` выполняет проверку данных и конвертацию валют;
- `tests/test_currency.py` содержит unit-тесты вычислительной логики;
- `.github/workflows/python-check.yml` запускает проверки на GitHub Actions.

## Особенности реализации

Для вычислений используется `Decimal`, поэтому суммы не получают погрешности
двоичных чисел с плавающей точкой. Поддерживаются точка и запятая в качестве
десятичного разделителя. Пустые, отрицательные, нулевые, бесконечные и
нечисловые значения обрабатываются без падения приложения: сообщение об ошибке
выводится на вкладке конвертера.

Курсы валют зафиксированы в программе и используются только для демонстрации:

| Валюта | Стоимость единицы в рублях |
|---|---:|
| RUB | 1,00 |
| USD | 82,50 |
| EUR | 97,00 |
| CNY | 11,50 |

Окно можно растягивать: вкладки и их содержимое адаптируются к доступному
размеру. Дополнительное окно не декоративное: кнопка «Показать автора» меняет
его содержимое.

## Запуск

Требуется Python 3.10 или новее. Сторонние библиотеки для запуска приложения не
нужны, так как Tkinter входит в стандартную поставку Python.

```bash
python main.py
```

## Проверка

```bash
python -m compileall -q .
python -m pip install -r requirements-dev.txt
python -m flake8 .
python -m unittest discover -v
```

GitHub Actions автоматически выполняет проверку синтаксиса, стиля и все
unit-тесты при отправке изменений в ветку `main`, создании тега `lab5` и в
pull request. Кэш зависимостей CI привязан к файлу `requirements-dev.txt`.
